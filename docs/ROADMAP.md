## Cómo trabajar cada mejora

1. Crea un *Issue* con el punto de la lista.
2. Crea una rama para ese punto, por ejemplo `mejora/testimonios`.
3. Haz los cambios, súbelos y abre un *Pull Request* hacia `main`.
4. Revisa los cambios y fusiona el PR: GitHub Pages publica la nueva versión en uno o dos minutos.
